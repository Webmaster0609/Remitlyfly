Sandbox API documentation

Use these endpoints to connect your own test application to RemitlyFly. All examples are simulations only.

: This API cannot send, receive, or move real money. Never put your API key in public code, a website page, GitHub repository, or a screenshot. Use a secure server-side environment for your test application.

1. Base URL and authentication

Base URL:

https://yzjktqrmgdatdyvcpapa.supabase.co/functions/v1/remitlyfly-sandbox

For protected endpoints, send your test key in the x-rf-api-key header. Replace the placeholder below with the key you copied. Do not paste your key into this dashboard or share it with anyone.

x-rf-api-key: YOUR_RF_TEST_API_KEY

2. Check API health (no key required)

curl -i "https://yzjktqrmgdatdyvcpapa.supabase.co/functions/v1/remitlyfly-sandbox/health"

A successful response reports status: online, mode: TEST_ONLY, and real_money_enabled: false.

3. Read a configured exchange rate

curl -H "x-rf-api-key: YOUR_RF_TEST_API_KEY" \
"https://yzjktqrmgdatdyvcpapa.supabase.co/functions/v1/remitlyfly-sandbox/v1/rates?base_currency=USD&quote_currency=ETB"

Change the currency pair as needed. If no active sandbox rate exists, the API returns HTTP 404. A returned rate is indicative and for testing only.

4. Request a quote (does not create a transfer)

curl -X POST \
"https://yzjktqrmgdatdyvcpapa.supabase.co/functions/v1/remitlyfly-sandbox/v1/quotes" \
-H "Content-Type: application/json" \
-H "x-rf-api-key: YOUR_RF_TEST_API_KEY" \
-d '{
  "sender_country": "US",
  "receiver_country": "ET",
  "send_currency": "USD",
  "send_amount": 25
}'

5. Create a simulated transfer

curl -X POST \
"https://yzjktqrmgdatdyvcpapa.supabase.co/functions/v1/remitlyfly-sandbox/v1/transfers" \
-H "Content-Type: application/json" \
-H "x-rf-api-key: YOUR_RF_TEST_API_KEY" \
-d '{
  "sender_country": "US",
  "receiver_country": "ET",
  "send_currency": "USD",
  "send_amount": 25,
  "scenario": "pending",
  "metadata": {
    "client_reference": "demo-001"
  }
}'

Supported scenarios: pending, under_review, success, and failure. Success/failure are simulated statuses only. The response returns a transfer reference.

6. Check a transfer status

curl -H "x-rf-api-key: YOUR_RF_TEST_API_KEY" \
"https://yzjktqrmgdatdyvcpapa.supabase.co/functions/v1/remitlyfly-sandbox/v1/transfers/YOUR_TRANSFER_REFERENCE"

7. Cancel a simulated transfer

curl -X POST \
"https://yzjktqrmgdatdyvcpapa.supabase.co/functions/v1/remitlyfly-sandbox/v1/transfers/YOUR_TRANSFER_REFERENCE/cancel" \
-H "x-rf-api-key: YOUR_RF_TEST_API_KEY"

Supported codes and important responses

  • Sender country examples: US, GB, DE, FR, and other supported European codes.
  • Receiver country codes: ET, KE, NG, UG, TZ, ZA.
  • Sender currencies: USD, EUR, GBP.
  • 401: missing or invalid test API key. 403: key scope not permitted. 404: endpoint, transfer, or configured rate not found. 409: no active rate configured for a requested quote/transfer or action cannot be performed.

Keep your key private. If it is exposed, revoke it from the API key management area and create a replacement. These examples are for developer testing only; no live payout partners, licences, or real-money capability are implied.
